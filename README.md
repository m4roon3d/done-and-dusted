# Done & Dusted

**Plan it · Do it · Dust it.** A task manager with Google Keep import, due-time reminders, a red/amber/green dashboard and week planning.

One codebase, three ways to ship it:

| Target | Status | How |
|---|---|---|
| Web app (installable, works offline) | Ready | `npm run build`, host the `dist/` folder |
| Android app | Ready | `npm run android`, or the GitHub workflow builds the APK |
| iPhone app | Prepared | Add the iOS project on a Mac (steps below) |

## How it is built

- **Web app:** plain JavaScript modules bundled with Vite. No framework.
- **Native apps:** [Capacitor 8](https://capacitorjs.com) wraps the same web app in a native shell and gives it phone features.
- **Dictation:** the mic button turns speech into text with the phone's recogniser (native) or the browser's (web: Chrome, Edge, Safari). `parseDictation` in `src/core.js` then splits it into tasks with dates, categories and priority. No AI service or API key is involved.
- **Storage:** IndexedDB on the device, through Dexie. There is no server and no account. Backups are JSON files the person saves and restores from Settings.
- **Reminders:**
  - Android and iPhone: scheduled local notifications at each due time. They fire when the app is closed and carry **Done ✓** and **+1 hour** buttons.
  - Web: a chime and pop-up while the app is open, a browser notification if the tab is in the background, and a calendar-file export for alerts when it is closed.

```
index.html              page shell
src/main.js             screens: Tasks, Plan, Dashboard, Import
src/core.js             date parsing, categories, formatting (no DOM, unit-tested)
src/store.js            IndexedDB storage, backup and restore
src/notify.js           reminders (native and web)
src/speech.js           dictation: speech to text (native and web)
src/platform.js         web vs. native differences: file saving, haptics, back button
src/settings.js         Settings sheet and the Dashboard reminders panel
src/styles.css          all styling and animation
public/                 manifest, service worker, web icons
android/                Android Studio project (generated by Capacitor)
scripts/make-icons.mjs  redraws every icon from the brand mark
```

## Run it

Needs Node 22 or newer.

```bash
npm install
npm run dev        # web app at http://localhost:5173
npm test           # unit tests
npm run build      # production web build into dist/
```

## Web app

Host the `dist/` folder on any static host. It uses relative paths, so a sub-folder works.

- **Render:** create a Static Site from the repo; `render.yaml` has the settings.

Serve it over HTTPS. Offline support, installing to the home screen and notifications all need it.

## Android app

**Without installing anything:** push to `main`. The **Android APK** job in `.github/workflows/build.yml` builds the app and publishes it as the **latest** release. On your phone, open the repository's *Releases* page, download `done-and-dusted.apk` and open it to install.

**On your computer:** needs Android Studio (with SDK 36) and JDK 21.

```bash
npm run android        # builds the web app, syncs it, opens Android Studio → press Run
npm run android:apk    # or build android/app/build/outputs/apk/debug/app-debug.apk directly
```

Test builds are signed with the shared key in `android/app/debug.keystore`, so each new APK installs over the previous one. The build number shows at the bottom of *Settings* in the app.

**Play Store release:** in Android Studio use *Build → Generate Signed App Bundle*. Keep the keystore file safe and out of the repo; you need the same one for every update. Raise `versionCode` and `versionName` in `android/app/build.gradle` for each release.

App ID: `app.doneanddusted` (set in `capacitor.config.json`). Change it before the first store release if you want a different one; it cannot change afterwards.

## iPhone app (later)

Needs a Mac with Xcode, and an Apple Developer account to publish.

```bash
npx cap add ios
npx capacitor-assets generate --ios --iconBackgroundColor '#E39A14' --splashBackgroundColor '#EEF1F4' --splashBackgroundColorDark '#0E141A'
npm run ios            # opens Xcode → choose a device → Run
```

Add two lines to `ios/App/App/Info.plist` for dictation: `NSSpeechRecognitionUsageDescription` and `NSMicrophoneUsageDescription`, each with a short reason such as "Used to dictate tasks". No other code changes are needed. Storage, reminders, backup sharing and haptics already go through Capacitor plugins that support iOS, and the layout respects the notch and home indicator. iOS keeps at most 64 pending notifications per app, so the app schedules the 60 soonest tasks and tops up whenever it opens.

## After changing the web code

```bash
npm run build && npx cap sync
```

That copies the new build into the native projects.

## Icons

`node scripts/make-icons.mjs` redraws the web icons and the source images in `assets/`. Add `--android` to redraw the notification icon too. Then run `npm run assets` to regenerate the Android (and, once added, iOS) launcher icons and splash screens. The script needs Playwright (`npm i -D playwright && npx playwright install chromium`).

## Known limits

- Tasks do not sync between devices. Use *Settings → Save a backup* and *Restore from backup* to move them.
- On Android 12 and newer, reminders at the exact minute need the "Alarms & reminders" permission. The app offers a button for it; without it, alerts can arrive a few minutes late.
- Some phone makers' battery savers delay notifications for apps that are rarely opened. Excluding the app from battery optimisation fixes it.
